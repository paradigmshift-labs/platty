# 시각 언어 계약

## 색상

사용 가능한 HEX는 아래 13개뿐이다. 컬러명은 코드 내부 별칭으로만 쓰고, 최종 CSS·SVG 값은 허용 HEX로 귀결시킨다.

| 토큰 | HEX | 권장 역할 |
| --- | --- | --- |
| raven-99 | `#FBFCFD` | 가장 옅은 면 |
| raven-95 | `#F8F9FC` | 옅은 면 |
| raven-90 | `#F2F4F8` | 캔버스·선택 배경 후보 |
| raven-80 | `#E3E7ED` | 분리 면·경계 후보 |
| raven-70 | `#CED3DE` | 경계·비활성 면 후보 |
| raven-60 | `#969FB0` | 보조 아이콘 후보 |
| raven-50 | `#6C7689` | 보조 텍스트 후보 |
| raven-40 | `#4D576A` | 중간 정보 후보 |
| raven-30 | `#30394B` | 본문 후보 |
| raven-20 | `#212A3B` | 강조 후보 |
| raven-10 | `#141B2A` | 핵심 정보 후보 |
| raven-5 | `#0B111D` | 가장 짙은 강조 후보 |
| white | `#FFFFFF` | 기본 화면·컨트롤 면 |

이 역할은 와이어프레임 가독성을 위한 출발점이지 히로인스 프로덕션 디자인 토큰의 의미 매핑이 아니다. 특히 제품의 보라색 미확인 배경이나 주의 색상은 Raven만으로 정확히 표현할 수 없다. 상태의 뜻을 문구·형태·위치로도 전달하고, 근사임을 메모에 기록한다. 다른 HEX, RGB/RGBA, HSL/HSLA, 색 이름, 그라데이션은 사용하지 않는다. 투명도에 기대어 새 색을 만들지 않는다.

## 참고 이미지에서 차용할 형식

- 밝은 회색 캔버스 위에 흰 모바일 화면을 같은 크기로 놓는다. 화면 사이 공간을 넉넉히 두어 한눈에 상태를 비교한다.
- 화면 내부는 평평한 면, 충분한 여백, 간결한 선·구분선, 절제된 둥근 모서리로 구성한다. 그림자와 입체 효과는 쓰지 않는다.
- 제목·핵심 상태·주요 행동을 먼저 읽고, 설명·메타데이터가 뒤따르도록 서체 크기·굵기·명암을 나눈다. 한 화면과 한 컴포넌트 안의 상대적 중요도를 함께 본다.
- 실제 이미지가 필요하지만 제공되지 않은 자리만 단색 플레이스홀더로 표시한다. 플레이스홀더는 실제 이미지나 실패 시 대체 이미지를 뜻하지 않는다. FSD가 이미지를 요구하지 않으면 빈 이미지 칸도 만들지 않는다.
- 아이콘은 의미가 확인된 조작이나 정보에만 단순 윤곽선으로 쓴다. 의미 없는 장식 문자·가짜 수치·가짜 OS 상태바는 넣지 않는다. 플랫폼 크롬이 필요하면 제품 범위 밖이라는 것을 표시한다.
- 모서리, 여백, 너비는 읽기와 비교를 돕는 와이어프레임 값이다. FSD나 현행 코드가 정하지 않은 정확한 치수를 제품 명세처럼 기록하지 않는다.

## 컴포넌트 선택

행, 카드, 탭, 칩, 배너, 바텀시트, CTA는 정보와 행동 관계가 요구할 때만 사용한다. 현행 화면을 바꾸는 FSD라면 기존 컴포넌트와 주변 영역의 관계를 먼저 확인한다. 독립된 행동은 버튼으로, 이동 가능한 행은 행으로 표현하되 복합 조작은 키보드·스크린리더에서 중첩 버튼이 되지 않게 한다. 상단·본문·하단의 위치 관계도 FSD 또는 확인된 기존 화면에서 가져온다.
