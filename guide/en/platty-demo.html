Troubleshooting

Evidence and limits

Before you start: Codex and Git are already installed, and you are already signed in to Codex. Have your MEKO access token ready. This guide starts with registering the Platty plugin.

The skill tells Codex how to investigate. The MCP connection lets Codex read MEKO project data. You will set up both below.

Screenshots show Codex CLI 0.160.0 on Linux. Your version or computer may look different. Use Enlarge screenshot to read a screen at its original size.

1. Add the English skill

Open a terminal on the host where you already use Codex. Run these commands to register the Platty marketplace and install its plugin. Use the demo branch explicitly. It contains one plugin and one skill, with all eight English reference files.

codex plugin marketplace add paradigmshift-labs/platty --ref feat/demo
codex plugin add platty@meko-poc
codex plugin list

Ready to continue: platty@meko-poc is installed and enabled.

If another marketplace already uses meko-poc, check its source before replacing it. If another installed plugin exposes the same skill, select this delivery explicitly or disable the conflicting plugin for the session.

2. Find the installed skill

Open a new terminal session with codex. Type /skills and press Enter. Choose List skills and press Enter again.

Type platty while the skill picker is open to narrow the list. Select platty-search (platty) and press Enter.

Ready to continue: selecting the skill inserts $platty:platty-search. This confirms skill recognition.

3. Paste your Bearer token

Open ~/.codex/config.toml on the computer or host running Codex. Add the block below. If platty already exists, update that entry instead of adding a duplicate.

Replace only YOUR_MEKO_TOKEN with the token supplied by your administrator. Keep Bearer and the space after it. If you received a full Bearer … value, replace the whole value inside the quotes so the prefix appears once.

[mcp_servers.platty]
url = "https://meko-poc.platty-ai.com/mcp"
http_headers = { Authorization = "Bearer YOUR_MEKO_TOKEN" }

For this entry, remove an old bearer_token_env_var setting or another Authorization source when switching to direct token input. Preserve unrelated servers and settings.

Ready to continue: the file is saved with platty, the exact MEKO URL, and Authorization = "Bearer …". Restart Codex to load it.

The token is saved in your personal configuration. See the official Codex MCP configuration for static HTTP headers.

4. Verify the actual connection

Restart Codex after saving your token. Run /mcp and check that platty is connected. Approve the intended read tools if your client asks.

Now send the following prompt to verify which project and repositories your account can read:

Use only the platty MCP connection. Check context_status and project_get,
then list the authorized repositories. Confirm that the project is petshop-full.
Report unavailable capabilities. Do not print credentials or use another
MCP connection. Answer in English.

Successful setup requires a real project/repository call and a real document or source read. A plugin in a list or a green connection label alone does not verify every tool. If the project differs, stop and check the endpoint and access scope with the administrator.

The publisher observed ten available repositories and an October 30, 2026 source snapshot on November 2. Your permitted repositories or later snapshots may differ.

5. Ask your first question

Select platty-search from the skill picker, or use this prompt. It asks the assistant to inspect the save API's source; it does not execute the API.

$platty:platty-search Explain what POST /on/ctrt/tnnt/saveCtrtTnntList does.
Use only platty, answer in English, and cite the source locations.
Do not execute the API or change any data.

What a useful answer contains: an English explanation, exact repository/file/line references, and any missing evidence. Ask Codex to read a cited source if no document or source read has succeeded yet.

When something does not work

401 Unauthorized / AUTHENTICATION_REQUIRED

Confirm that YOUR_MEKO_TOKEN was replaced by a valid token in the active config file. Check the exact URL, a single Bearer prefix and duplicate server entries. Restart the client. Ask the administrator to validate or reissue the token if it persists.

403, missing repositories, or a different project

Check the endpoint and that token's project/repository permissions with the administrator. Do not substitute another MCP connection or assume its data belongs to MEKO.

The skill is missing

Check that platty@meko-poc is installed and enabled, then start a new session. Use this package's skill picker entry when another distribution has the same skill name.

The plugin command or branch cannot be found

Check codex plugin --help and confirm your installed client supports the plugin commands. Use --ref feat/demo; the default branch is a different distribution. Confirm that Git is installed and GitHub is reachable from the execution host.

A source path does not exist, or search is incomplete

Use the exact repository-relative path returned by source search, including its module prefix. Follow continuation cursors and resolve truncated/timed-out repositories before concluding that a writer or feature is absent.

The token was saved, but a desktop or remote session still fails

That session may run on another host or have a different environment. Edit the configuration on the actual execution host and restart the client. Do not disable TLS certificate checks to work around a connection failure.

For support, provide client/version, execution host, project, prompt/identifier, tool name, error code and time with timezone. Remove access credentials and confidential source excerpts before sharing logs.

What the answers can establish

Platty reads analyzed source code and project documents. It can explain code paths and SQL, but it cannot infer today's production rows, permissions, actual execution outcomes, or external-system behavior from a source snapshot.

These gaps do not mean authentication failed. They must remain explicit in the answer. Generated documents may need review; source confirmation requires reading the relevant code. An incomplete empty search never proves absence.

Remove this delivery
codex plugin remove platty@meko-poc
codex plugin marketplace remove meko-poc
codex mcp remove platty

Remove only the intended MEKO connection. Close active sessions and remove the saved token when access is no longer needed. Uninstalling a plugin does not revoke its server token; ask the administrator to revoke access when required.
