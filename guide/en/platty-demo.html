Troubleshooting

Evidence and limits

1. Install Codex and sign in

You need a Codex account, Git for the direct Git installation method, and a MEKO access token from your administrator. The MEKO token is separate from your AI account credentials.

If Codex is already installed, run codex --version and continue. For macOS or Linux, use the current official installer:

curl -fsSL https://chatgpt.com/codex/install.sh | sh
codex --version
codex

Complete sign-in, then exit Codex before configuration. Native Windows users should follow the Windows tab in the official guide; Bash commands in this document require Bash or WSL.

Run configuration on the same computer or remote host where Codex makes MCP requests. A laptop's settings do not automatically configure a remote VM.

2. Add the English skill

Use the demo branch explicitly. It contains one plugin and one skill, with all eight English reference files.

codex plugin marketplace add paradigmshift-labs/platty --ref feat/demo
codex plugin add platty@meko-poc
Install from the downloaded ZIP instead

Extract the installation ZIP to a permanent folder. Open a terminal in its meko-poc folder containing README.md, .agents, .claude-plugin, and plugins.

codex plugin marketplace add .
codex plugin add platty@meko-poc

Keep the extracted folder in place. The skill-only ZIP is for reviewing or replacing skill files in an existing installation; it does not configure MCP or contain plugin manifests.

3. Load your MEKO access token

Obtain a valid token from your administrator. Enter the token alone, without Bearer . Use the same terminal to start Codex afterward. Do not paste your token into a chat.

read -r -s -p 'MEKO PoC token: ' MEKO_POC_TOKEN
printf '\n'
export MEKO_POC_TOKEN
test -n "$MEKO_POC_TOKEN" && printf 'Token loaded (value hidden).\n'
$mekoSecureToken = Read-Host 'MEKO PoC token' -AsSecureString
$env:MEKO_POC_TOKEN = [System.Net.NetworkCredential]::new('', $mekoSecureToken).Password

The value is hidden while you enter it. It lasts for this shell and child processes; a new shell needs the token loaded again. A desktop app launched elsewhere may not inherit it. Use your organization's approved secret manager for persistent access.

4. Register MCP as platty

Installing the skill and connecting the server are separate steps. Register the exact endpoint:

codex mcp add platty --url https://meko-poc.platty-ai.com/mcp --bearer-token-env-var MEKO_POC_TOKEN
Configure config.toml manually

Merge this section into ~/.codex/config.toml on the execution host. Preserve unrelated settings. Codex adds the Bearer header from the named environment variable.

[mcp_servers.platty]
url = "https://meko-poc.platty-ai.com/mcp"
bearer_token_env_var = "MEKO_POC_TOKEN"

If a platty connection already exists, inspect its endpoint and project before changing it. Update the intended entry instead of creating duplicate TOML tables. Remove a stale static Authorization header when switching that entry to the environment token.

See the official Codex MCP guide for client configuration. A local alias does not prove the server's identity; verify the project next.

5. Verify the actual connection

Start a new Codex session from the token-loaded terminal. Run /mcp and check that platty is connected. Approve the intended read tools if your client asks.

Use only the platty MCP connection. Check context_status and project_get,
then list the authorized repositories. Confirm that the project is petshop-full.
Report unavailable capabilities. Do not print credentials or use another
MCP connection. Answer in English.

Successful setup requires a real project/repository call and a real document or source read. A plugin in a list or a green connection label alone does not verify every tool. If the project differs, stop and check the endpoint and access scope with the administrator.

The publisher observed ten available repositories and an October 30, 2026 source snapshot on November 2. Your permitted repositories or later snapshots may differ.

6. Ask a source-backed question

Select platty-search from the skill picker, or use this prompt. It asks the assistant to inspect the save API's source; it does not execute the API.

$platty:platty-search Explain what POST /on/ctrt/tnnt/saveCtrtTnntList does.
Use only platty, answer in English, and cite the source locations.
Do not execute the API or change any data.

When something does not work

401 Unauthorized / AUTHENTICATION_REQUIRED

Confirm a valid MEKO token is loaded on the host starting Codex. Check the variable name, duplicate server entries and stale static Authorization headers. Restart the client. Ask the administrator to validate or reissue the token if it persists.

403, missing repositories, or a different project

Check the endpoint and that token's project/repository permissions with the administrator. Do not substitute another MCP connection or assume its data belongs to MEKO.

The skill is missing

Check that platty@meko-poc is installed and enabled, then start a new session. Use this package's skill picker entry when another distribution has the same skill name.

The plugin command or branch cannot be found

Check codex plugin --help and update the client through its official installation instructions. Use --ref feat/demo; the default branch is a different distribution. The installation ZIP is an alternative to the Git method.

A source path does not exist, or search is incomplete

Use the exact repository-relative path returned by source search, including its module prefix. Follow continuation cursors and resolve truncated/timed-out repositories before concluding that a writer or feature is absent.

A token was loaded, but a desktop or remote session still fails

That session may run on another host or have a different environment. Configure the actual execution host or start the CLI from the token-loaded terminal. Do not disable TLS certificate checks to work around a connection failure.

For support, provide client/version, execution host, project, prompt/identifier, tool name, error code and time with timezone. Remove access credentials and confidential source excerpts before sharing logs.

What the answers can establish

Platty reads analyzed source code and project documents. It can explain code paths and SQL, but it cannot infer today's production rows, permissions, actual execution outcomes, or external-system behavior from a source snapshot.

These gaps do not mean authentication failed. They must remain explicit in the answer. Generated documents may need review; source confirmation requires reading the relevant code. An incomplete empty search never proves absence.

Remove this delivery
codex plugin remove platty@meko-poc
codex plugin marketplace remove meko-poc
codex mcp remove platty

Remove only the intended MEKO connection. Close active sessions and clear the environment variable when finished. Uninstalling a plugin does not revoke its server token; ask the administrator to revoke access when required.
