Platty Search for Codex

Install the plugin from Git, paste your Platty token, and ask questions backed by project source.

Prepared November 2, 2026 (Asia/Seoul). The six screenshots are embedded in this file for offline sharing. Setup and project queries require network access.

Before you start: Codex and Git are already installed, and you are already signed in to Codex. Have the Platty access token supplied by your administrator ready.

The skill tells Codex how to investigate. The platty MCP connection gives it access to authorized project documents and analyzed source. Set up both below.

Screenshots show Codex CLI 0.160.0 in a Linux terminal. Other versions may look different. Use Enlarge screenshot to read the original image.

1. Install the Platty skill

Codex Claude Code

Open your terminal and run these commands. Keep --ref feat/demo: the default branch contains a different distribution.

codex plugin marketplace add paradigmshift-labs/platty --ref feat/demo
codex plugin add platty@platty
codex plugin list

Ready to continue: platty@platty is installed and enabled. The marketplace and plugin are both named platty; the skill is platty-search.

2. Paste your Platty token

Open ~/.codex/config.toml on the computer or host running Codex. Add the block below. If platty already exists, update that entry instead of adding a duplicate.

Replace only YOUR_PLATTY_TOKEN with the token supplied by your administrator. Keep Bearer and the space after it. If you received a full Bearer … value, replace the whole value inside the quotes so the prefix appears once.

[mcp_servers.platty]
url = "https://meko-poc.platty-ai.com/mcp"
http_headers = { Authorization = "Bearer YOUR_PLATTY_TOKEN" }

For this entry, remove an old bearer_token_env_var setting or another Authorization source when switching to direct token input. Preserve unrelated servers and settings.

Ready to continue: the file is saved with platty, the exact Platty URL, and Authorization = "Bearer …". Restart Codex to load it.

3. Check the actual connection

Restart Codex after saving your token. Run /mcp and check that platty is connected. Approve the intended read tools if your client asks.

Send this English prompt to verify the project and read access:

Use only the platty MCP connection. Check context_status and project_get,
then list the authorized repositories. Confirm that the project is petshop-full.
Report unavailable capabilities. Read one source file to verify source access.
Do not print credentials, execute application APIs, or change data.
Answer in English.

Codex should identify petshop-full and return a source reference. If access fails or another project appears, check the token and endpoint with your Platty administrator.

4. Find the Platty skill

Open a new terminal session with codex. Type /skills and press Enter. Choose List skills and press Enter again.

Type platty while the skill picker is open to narrow the list. Select platty-search (platty) and press Enter.

Ready to continue: the prompt contains $platty:platty-search. Add a space and your question before submitting it.

5. Ask your first question

Copy this prompt into Codex and press Enter to submit it:

$platty:platty-search In SHOP0103, what is the difference between Save and Confirm? Answer in English and cite source locations. Do not execute APIs or change data.

What a useful answer contains: an English explanation of Save versus Confirm, exact repository/file/line evidence, and explicit unknowns about backend persistence and actual execution.

More questions to try
