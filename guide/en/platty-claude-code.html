Platty Search for Claude Code

Install the plugin from Git, paste your Platty token, and ask questions backed by project source.

Prepared November 2, 2026 (Asia/Seoul). The four screenshots are embedded in this file for offline sharing. Setup and project queries require network access.

Before you start: Claude Code and Git are already installed, and you are already signed in to Claude Code. Have the Platty access token supplied by your administrator ready.

The skill tells Claude how to investigate. The platty MCP connection gives it access to authorized project documents and analyzed source. Set up both below.

Screenshots show Claude Code 2.1.311 in a Linux terminal. Other versions may look different. Use Enlarge screenshot to read the original image.

1. Install the Platty skill

Claude Code Codex

Open your terminal and run these commands. Keep #feat/demo in the Git URL: the default branch contains a different distribution.

claude plugin marketplace add https://github.com/paradigmshift-labs/platty.git#feat/demo --scope user
claude plugin install platty@platty --scope user
claude plugin list

Ready to continue: platty@platty appears with Status: ✔ enabled. The marketplace and plugin are both named platty; the skill is platty-search.

This installs the skill for your Claude Code user. The MCP connection in the next step is configured for the project folder where you will use it. A global Platty CLI installation is not required.

2. Paste your Platty token

In your project folder, open or create .mcp.json. Merge this server entry into the file, preserving unrelated servers.

{
  "mcpServers": {
    "platty": {
      "type": "http",
      "url": "https://meko-poc.platty-ai.com/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_PLATTY_TOKEN"
      }
    }
  }
}

Replace only YOUR_PLATTY_TOKEN with your Platty token. Keep Bearer and its space. If your administrator supplied the full Bearer … value, replace the entire quoted value so the prefix appears once.

Save the file and keep the filled version out of Git and shared screenshots. If .mcp.json already exists, add only the platty entry. Update an existing entry instead of duplicating it.

Ready to continue: the project folder contains .mcp.json with server name platty, the exact URL above, and your token. Open a new Claude Code session in this same folder.

3. Check the actual connection

Run claude in the project folder. If Claude asks you to trust the folder or approve its project MCP server, review the platty entry and URL. Then enter /mcp.

Ready to continue: find platty under Project MCPs with a connected checkmark and available tools. Other connectors and tool counts can differ. This test showed 59 Platty tools.

Send this English prompt to verify the project and read access:

Use only the platty MCP connection. Check context_status and project_get,
then list the authorized repositories. Confirm that the project is petshop-full.
Report unavailable capabilities. Read one source file to verify source access.
Do not print credentials, execute application APIs, or change data.
Answer in English.

Claude should identify petshop-full and return a source reference. If access fails or another project appears, check the token and endpoint with your Platty administrator.

4. Find the Platty skill

In the Claude Code prompt, type /platty:. Find /platty:platty-search in the command suggestions and press Tab to complete it.

Ready to continue: the prompt contains /platty:platty-search. Add a space and your question before submitting it.

Claude Code skill commands start with a slash: /platty:platty-search.

5. Ask your first question

Copy this prompt into Claude Code and press Enter to submit it:

/platty:platty-search In SHOP0103, what is the difference between Save and Confirm? Answer in English and cite source locations. Do not execute APIs or change data.

What a useful answer contains: an English explanation of Save versus Confirm, exact repository/file/line evidence, and explicit unknowns about backend persistence and actual execution.

More questions to try

  • Does SHOP0104 refresh every 60 seconds? Read the timer handler and cite the source.
  • In SHOP0201, what does the Total label count? Distinguish it from the sales column.
  • In SHOP0501, how is progress status loaded and saved? Separate proven code behavior from unverified status values and transitions.
